# AI Short Drama Production

**English** · [繁體中文](README.zh-TW.md)

An agent skill for producing a finished vertical AI short drama — typically 60 seconds — end to
end, using the [Kling](https://kling.ai) API plus ffmpeg.

It covers the whole chain: story structure, multi-shot generation plans, cross-segment character
consistency, native-language dialogue with lip sync, ambience and BGM design with sidechain
ducking, subtitle burn-in, and loudness normalisation.

The whole workflow is scripted. Generation is asynchronous, resumable and ledgered, so a re-run
never re-bills a segment that already exists on disk.

## Requirements

- A Kling API key with a purchased resource package (trial packages are enough).
  Create one at <https://kling.ai/dev/api-key> · pricing at
  <https://kling.ai/dev/pricing?scrollTo=video>
- Node.js 18+ — the scripts have **no npm dependencies** (`https`, `fs`, `child_process` only)
- ffmpeg + ffprobe. If you don't have them, `scripts/get-ffmpeg.js` downloads a static build

## Install

This is an [agent skill](https://kling.ai/document-api/llms.txt) — a directory containing a
`SKILL.md` plus supporting files. Drop it into your personal skills directory:

```bash
git clone https://github.com/goordonbear/ai-short-drama-production.git \
  ~/.agents/skills/ai-short-drama-production
```

The agent picks it up on the next session, and it becomes usable from any project.

## Quick start

```bash
mkdir my-drama && cd my-drama
cp ~/.agents/skills/ai-short-drama-production/production-template.json production.json
# edit production.json: title, character sheet, and one prompt per segment

export KLING_API_KEY='api-key-kling-...'      # or write ./.kling.key

node ~/.agents/skills/ai-short-drama-production/scripts/kling-gen.js --check     # free
node ~/.agents/skills/ai-short-drama-production/scripts/kling-gen.js --dry-run   # free
node ~/.agents/skills/ai-short-drama-production/scripts/kling-gen.js --test S1   # generate one, look at it
node ~/.agents/skills/ai-short-drama-production/scripts/kling-gen.js --all       # the rest
node ~/.agents/skills/ai-short-drama-production/scripts/kling-ambience.js        # SFX layer
node ~/.agents/skills/ai-short-drama-production/scripts/kling-bgm.js             # BGM cues
node ~/.agents/skills/ai-short-drama-production/scripts/assemble.js              # concat + subtitles
node ~/.agents/skills/ai-short-drama-production/scripts/final-mix.js             # mix + loudness
```

Every script reads its plan from the **current working directory**, so run them from inside the
project. Status messages are printed in Chinese.

## Cost

Billing is per second of rendered video, in resource-package units. A 60-second vertical drama at
720p, built as six multi-shot calls, is roughly **36 units**; adding native speech to two segments
is about **+18**; ambience and BGM cues are **~2**. Check the live price table before budgeting —
`reference.md` holds a dated snapshot, not a contract.

The workflow is designed to spend as little as possible while learning what works:
`--check` (free) → `--dry-run` (free) → one test segment → the rest. Regenerating a single segment
is the normal repair action.

## Design notes

A few decisions that came out of building this for real:

- **Six calls, not fourteen.** Kling 3.0 accepts a multi-shot prompt
  (`shot 1, 4, ...; shot 2, 3, ...`), so one 10-second generation can carry three to four shots.
  Fewer calls cost less and keep a segment internally consistent.
- **The character sheet goes first, verbatim, in every segment.** Traits described mid-prompt get
  dropped. This is also the entire mechanism for consistency across independently generated
  segments.
- **Dialogue is generated by the video model, not bolted on.** `settings.audio: "native"` with the
  line written into the prompt produces speech and matching mouth movement together. A separate TTS
  step plus a lip-sync pass is a fallback, and the TTS voice library is account-gated.
- **Verify by looking, not by assuming.** You cannot watch or listen to the output, so the workflow
  converts it into something inspectable: contact sheets for the picture, spectrograms for the
  audio, `loudnorm`/`volumedetect` for the mix.
